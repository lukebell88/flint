# Flint

A general-purpose icon set. 463 icons, six weights from hairline to solid,
every corner on the half pixel.

**[flinticons.com](https://www.flinticons.com)**

Available as SVG, React, SwiftUI, CSS, and a Figma plugin.

| Style | Weight |
| --- | --- |
| Thin | 1 |
| Light | 1.25 |
| Regular | 1.5 |
| Bold | 2.25 |
| Fill | 2 |
| Duotone | 1.5 |

## Requesting an icon

This repository is where icon requests live. Open one with the
[icon request form](https://github.com/lukebell88/flint/issues/new/choose),
or just [say what you need](https://github.com/lukebell88/flint/issues/new).

Worth saying what the icon is *for* rather than only what it should look like.
Half the time there is already something in the set that does the job, and the
other half the use case is what decides how it should be drawn.

## Reporting a problem

Same place. An icon that looks wrong at a particular size, a weight that reads
too light or too heavy, a name that is hard to find by searching: all of it is
useful, and all of it goes in [issues](https://github.com/lukebell88/flint/issues).
